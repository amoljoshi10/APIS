# Security Awareness Training

## Overview
All contributors to this project must complete the mandatory security awareness training curriculum.

## Mandatory Training (Annual)

### Module 1 — OWASP Top 10 (2 hours)
- [ ] A01: Broken Access Control
- [ ] A02: Cryptographic Failures
- [ ] A03: Injection
- [ ] A04: Insecure Design
- [ ] A05: Security Misconfiguration
- [ ] A06: Vulnerable & Outdated Components
- [ ] A07: Identification & Authentication Failures
- [ ] A08: Software & Data Integrity Failures
- [ ] A09: Security Logging & Monitoring Failures
- [ ] A10: Server-Side Request Forgery

### Module 2 — Secure Coding Practices (1 hour)
- [ ] Input validation and sanitisation
- [ ] Secret management — never hardcode credentials
- [ ] Dependency management and CVE awareness

### Module 3 — Social Engineering & Phishing (1 hour)
- [ ] Recognising phishing emails
- [ ] Safe handling of credentials
- [ ] Incident reporting procedures
