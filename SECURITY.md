# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | :white_check_mark: |
| < Latest| :x: |

## Reporting a Vulnerability

Please report security vulnerabilities via our private disclosure process:

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email: security@your-org.com (or use GitHub's private vulnerability reporting)
3. Include: description, steps to reproduce, impact, and any suggested fix

We will acknowledge your report within 48 hours and provide a resolution timeline.

## Security Practices

- Dependencies are automatically updated via Dependabot
- All PRs require security review for sensitive changes
- Container images are scanned for CVEs on every build
- Secrets are never committed to source control
