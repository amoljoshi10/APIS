# Security Champions Program

## Purpose
Security Champions are developers embedded in each team who act as the local security conscience,
bridge between the central security function and development teams.

## Responsibilities
- Attend monthly Security Champions community of practice
- Review security requirements in sprint planning
- Perform preliminary security review of new features
- Escalate security concerns to the security team
- Promote secure coding practices within their team

## Activities
- [ ] Complete advanced OWASP Top 10 training (champion-level)
- [ ] Review threat models for features in their area
- [ ] Participate in tabletop exercises
- [ ] Present security topic at team meeting each quarter

## Recognition
Security Champions are recognised in the company all-hands each quarter
for their contributions to the security culture.
